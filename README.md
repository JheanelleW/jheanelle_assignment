# The Office: Did Ratings Decline After Michael Scott Left?

This project analyzes IMDb episode ratings for The Office (US) to examine whether ratings declined after Michael Scott's departure in Season 7, and whether that decline was unique to the post-departure period.

## Live site
https://jheanellew.github.io/jheanelle_assignment/

## Contents
- `index.qmd` — Quarto source file containing all data cleaning, analysis, and visualization code
- `_quarto.yml` — Quarto project configuration
- `docs/` — rendered HTML output, published via GitHub Pages

## Data source
Data sourced from the `schrute` R package (CRAN), originally compiled for the TidyTuesday (2020-03-17) community data project.

## Reproducing this analysis
1. Clone this repository
2. Open `jheanelle_assignment.Rproj` in RStudio
3. Install required packages: `tidyverse`, `schrute`
4. Run `quarto render` to regenerate the site
